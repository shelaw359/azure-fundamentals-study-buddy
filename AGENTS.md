## Project rules

- AI calls go only through the streaming server route `src/routes/api/chat.ts` → `src/lib/ai/chat.server.ts` (Lovable AI Gateway, Responses API); keeps the key and prompt server-side.
- The tutor system prompt lives in `src/lib/ai/tutor-prompt.ts` and must stay verbatim to the brief; language and topic are appended per request.
- Quiz data comes from a `<quiz>{json}</quiz>` tail parsed by `src/lib/quiz.ts`; parsing must never throw.
- Chat, topic, language, quiz answers and streak persist in localStorage (one conversation, no login); no database.
- Service worker is generated by vite-plugin-pwa into `dist/client` (TanStack Start client output) and registered only via `src/lib/pwa.ts`, which refuses dev/preview/iframe; manifest is the static `public/manifest.webmanifest`.
- Streamdown code/math/mermaid plugins are intentionally omitted from `MessageResponse` to keep the offline app shell small.
- Rule tests live in `src/test/study-rules.test.ts`.
